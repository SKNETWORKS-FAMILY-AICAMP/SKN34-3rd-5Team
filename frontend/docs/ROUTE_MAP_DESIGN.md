# 경로 표시 비교와 적용 (2026-09-12)

공식 안내와 공개 화면을 비교했다. 모든 서비스의 최신 앱을 설치하거나
같은 왕복 코스를 실사용한 비교는 아니다. 특히 카카오의 2020년 화면은
경유지·경로 선택 방식의 참고 자료이며 현재 UI와 완전히 같다고 보지 않는다.

## 이전 비교안 (아래 변경으로 대체)

- 파란 선과 얇은 흰 외곽선. 구간마다 달랐던 무지개색 제거.
- 전체 화면에서는 방향 표시 최대 3개, 구간당 1개. 원형 배경 없이 흰 꺾쇠를 선 위에 표시.
- 선택한 구간만 진한 파랑, 다른 구간은 회색. 선택 구간을 마지막에 그려 겹친 경로에도 보이도록 함.
- `출발 → 1`, `1 → 2`처럼 지도 번호와 구간 선택 버튼을 맞춤.
- 이전·다음 구간 버튼으로 같은 길을 오가는 순서를 차례로 확인.
- 경로 좌표를 옆으로 밀거나 가상의 평행 도로를 만들지 않음. 겹침은 구간 선택으로 확인.

화살표의 정확한 개수·간격과 구간 강조는 이 프로젝트에 맞춘 설계다.
위 서비스 모두가 같은 방식으로 겹침을 처리한다고 주장하지 않는다.

## 사용자 피드백 반영: 겹친 선의 색 분할

- 구간별 색상을 복원하고 목록의 색상 표시와 연결한다.
- 동일한 길의 겹친 부분은 한 선의 폭 안에서 색을 나란히 나눈다. 두 구간은 반씩, 세 구간 이상은 구간 수만큼 나눈다.
- 진행 방향이 반대이거나 API 좌표의 분할 단위가 달라도 공통 부분을 분리한다. 교차로와 별도의 평행 도로는 겹침으로 처리하지 않는다.
- 분석은 미터 단위로 처리해 지도 축척에 따라 겹침 여부가 바뀌지 않는다. 표시 폭만 화면 픽셀 단위로 유지한다.
- 전체 선 외곽선을 먼저 그리고 각 색을 한 번씩 표시한다. 선 이음새는 둥글게 처리하며 기본 선 끝 화살표와 무늬는 사용하지 않는다.
- 별도 방향 표시는 기존처럼 최대 3개만 유지한다. 위치는 해당 구간 색상 띠에 맞춘다.
- 코스 좌표·구간별 거리·시간 계산값은 변경하지 않는다.
