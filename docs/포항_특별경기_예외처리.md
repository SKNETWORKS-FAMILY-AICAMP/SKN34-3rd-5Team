# 포항 특별경기 챗봇 예외처리 스펙 (2026-09-08 작성)

## 배경

`data/preprocessed/kbo_schedule_full.csv`에 삼성 라이온즈가 홈구장(대구)이 아닌 **포항**에서
치르는 지역연고 특별경기 3건이 `stadium_code=OTHER`로 들어있다. 우리가 추적하는 9개 구장
(잠실·고척·문학·수원·대전·대구·광주·사직·창원)에 포함되지 않는 곳이라, 이 3경기에는
external_places(카카오 주변 정보)·편의시설·먹거리·교통·좌석/가격 등 어떤 전처리 데이터도
없다. 챗봇이 이 경기들을 다른 정규 경기와 똑같이 답변하면 "정보 없음"을 그럴듯하게
지어내거나(할루시네이션) 엉뚱한 대구 정보를 잘못 붙여줄 위험이 있어, LLM/백엔드 팀에서
별도 예외처리가 필요하다.

## 대상 경기 (3건, 전부 확정)

식별 조건: `kbo_schedule_full.csv`에서 `stadium_code == "OTHER"` (이 값을 가진 행은 현재
이 3건이 전부이며, 다른 원인으로 재사용되지 않는다).

## 권장 예외처리 로직

1. 사용자가 위 3개 game_id 중 하나에 대해 질문하거나(날짜로 매칭되는 경우 포함), 응답
   과정에서 RAG가 `stadium_code=OTHER`인 경기를 참조하게 되면, 아래 로직을 우선 적용한다.
2. **주변 정보(맛집·편의시설·교통·주차 등)를 절대 대구 데이터로 대체하지 않는다.** 포항은
   별도 데이터가 전혀 없으므로, 이 경기에 한해서는 "이 경기는 포항 특별경기라 주변 정보는
   제공하지 않습니다" 수준으로 명확히 안내하고 끝낸다.
3. 경기 일정 자체(날짜·시간·대진)는 `kbo_schedule_full.csv`에 이미 있으므로 정상 답변
   가능 — 예외처리 대상은 "주변 안내"류 질문에 한정된다.
4. 티켓 가격·반입물품 등 구단 공통 정책(삼성 라이온즈 소속 정책)은 원칙상 적용되지만,
   포항 임시 구장에는 구장 고유 예외가 있을 수 있어 확인이 안 된 상태다 — 답변 시
   "포항 특별경기는 대구 라이온즈 파크와 정책이 다를 수 있으니 구단 공식 채널 확인을
   권장합니다" 수준의 안내가 안전하다.

## 권장 답변 문구 (예시)

> "이 경기는 삼성 라이온즈의 포항 특별경기로, 저희가 안내해드리는 주변 맛집·편의시설·
> 교통 정보는 대구 삼성 라이온즈 파크 기준이라 포항 경기장에는 적용되지 않습니다.
> 포항 경기장 주변 정보는 구단 공식 채널에서 확인해주세요."
